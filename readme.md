📓 Smart Journal (AI-Powered Reflection)
Smart Journal is a modern journaling application that uses Google Gemini AI to provide instant insights, advice, and reflections on your daily thoughts. Instead of just storing text, this journal helps you process your day with the help of advanced Generative AI.

✨ Key Features
AI Insights: Every entry is analyzed by gemini-2.5-flash to provide meaningful feedback and advice.

Persistent History: Saves your entries and the AI's responses to a database (SQLite) so you can track your growth over time.

Clean Interface: A minimalist, user-friendly UI built with Django templates.

Real-time Processing: Get immediate AI reflections as soon as you save your entry.

🛠️ Tech Stack
Backend: Django 5.x

AI Integration: Google Generative AI (Gemini API)

Database: SQLite (default)

Frontend: HTML5 / CSS3

⚙️ Setup & Installation
1. Clone the repository

Bash
git clone https://github.com/Sunil2409/Smart_journal.git
cd Smart_journal
2. Install Dependencies

Ensure you have Python installed, then run:

Bash
pip install django google-generativeai
3. Configure Gemini API Key

To keep your key secure, it is recommended to use environment variables. In your views.py, ensure the key is fetched securely:

Python
# Create a .env file or set your environment variable
export GEMINI_API_KEY='your_api_key_here'
4. Database Migrations

Create the JournalEntry table in your local database:

Bash
python manage.py makemigrations
python manage.py migrate
5. Launch the Journal

Bash
python manage.py runserver
Navigate to http://127.0.0.1:8000 to start your first smart entry!

📂 Code Overview
Model (models.py)

The application uses a simple model to store the user's text and the AI's response:

user_text: The raw journal entry.

ai_advice: The response generated by Gemini.

created_at: Automatic timestamp for history tracking.

View Logic (views.py)

The logic follows a clean flow:

Fetch: Retrieves all past entries from the database.

Generate: When a new entry is posted, it sends the text to the Gemini gemini-2.5-flash model.

Save: Stores both the user input and AI response simultaneously.

🛡️ Security Note
This project is currently in development. Never commit your API keys directly to GitHub. Use python-dotenv or environment variables to keep your credentials safe.
